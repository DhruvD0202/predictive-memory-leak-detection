# IEEE and ACM reference additions

Updated: 15 September 2026.

Ten published works were added to the Literature Survey, increasing the bibliography from 36 to 46 distinct works. Six additions were published by IEEE, including one IEEE/ACM ICSE paper, and four by ACM. Each is cited where it informs the discussion. Citation numbers below match the revised manuscript and follow first appearance.

| Ref. | Paper and publication | Why it belongs in this project |
|---|---|---|
| 10 | [Cotroneo et al., A survey of software aging and rejuvenation studies](https://doi.org/10.1145/2539117), ACM JETC, 2014 | Places forecasting and rejuvenation within established aging research. |
| 11 | [Zhao et al., Injecting Memory Leaks to Accelerate Software Failures](https://doi.org/10.1109/ISSRE.2011.24), IEEE ISSRE, 2011 | Distinguishes observed failure outcomes from injection labels alone. |
| 13 | [De Sena and Matias, A Systematic Mapping Review of Memory Leak Detection Techniques](https://doi.org/10.1109/ISSREW.2018.00017), IEEE ISSREW/WoSAR, 2018 | Connects the aging literature with static and dynamic leak detection. |
| 14 | [Hauswirth and Chilimbi, Low-overhead memory leak detection using adaptive statistical profiling](https://doi.org/10.1145/1024393.1024412), ACM ASPLOS, 2004 | Explains a heap-access approach that differs from aggregate telemetry. |
| 15 | [Fan et al., SMOKE: Scalable Path-Sensitive Memory Leak Detection for Millions of Lines of Code](https://doi.org/10.1109/ICSE.2019.00025), IEEE/ACM ICSE, 2019; publisher IEEE | Adds a scalable static-analysis comparison without treating code-level bugs as telemetry forecasts. |
| 20 | [Matias et al., A Systematic Differential Analysis for Fast and Robust Detection of Software Aging](https://doi.org/10.1109/SRDS.2014.38), IEEE SRDS, 2014 | Introduces comparison against a previous software version as an alternative to recent-trend analysis. |
| 22 | [Salfner et al., A survey of online failure prediction methods](https://doi.org/10.1145/1670679.1670680), ACM Computing Surveys, 2010 | Relates runtime monitoring to the broader task of failure prediction. |
| 23 | [Avritzer et al., Software Aging Detection and Rejuvenation Assessment in Heterogeneous Virtual Networks](https://doi.org/10.1109/TETC.2025.3547612), IEEE TETC, 2025 | Adds recent operational context and reinforces the need to evaluate interventions separately. |
| 28 | [Greff et al., LSTM: A Search Space Odyssey](https://doi.org/10.1109/TNNLS.2016.2582924), IEEE TNNLS, 2017 | Grounds empirical architecture comparisons without claiming our fixed configuration is optimal. |
| 40 | [Chandola et al., Anomaly detection: A survey](https://doi.org/10.1145/1541880.1541882), ACM Computing Surveys, 2009 | Supports explicit anomaly definitions and assumptions before evaluating warnings. |

## Verification and access

Google Scholar is a discovery service, not a publication venue or proof of peer review. Its search page could not be accessed in this session, so no claim is made that Scholar records or citation counts were inspected. The citations above identify actual IEEE/ACM publications, verified through accessible publisher records, original papers, institutional records and publisher-deposited metadata. The [reference audit](REFERENCE_AUDIT.md) gives the exact reading scope and verification links for each work; not every full text was read.

Seven publisher metadata records were retrieved from Crossref; three other lookups were rate-limited and were not completed. Original-paper and institutional/proceedings evidence supported those citations instead. The audit does not claim all ten Crossref lookups succeeded.

The literature update adds no experimental results. All models, data, forecasts, warning rules and reported scores remain those from the completed Colab pilot. Publication venue alone is not treated as evidence that a method is superior or directly comparable with this project.
